01 / ABOUT

Hardware first,
silicon always.

I got into chip design through hardware — building PCBs, debugging embedded firmware, and tracing signals with a logic analyzer before writing any RTL. That hands-on instinct still shapes how I work: I want to see the waveform, not just trust the theory.

Right now my focus is physical design — taking RTL through synthesis, floorplanning, placement, and routing to watch it become silicon. I run these flows independently using OpenROAD, documenting each stage rather than treating it as a black box.

Based in Bengaluru, which puts me close to a dense cluster of chip design hiring — an advantage I plan to use.

16-bit ALU — RTL to GDS

CLEAN TIMING · 0 DRC

Complete physical design flow run independently through OpenROAD on the Nangate45 PDK: synthesis, floorplanning, placement, CTS, and routing. Final result: 3,072 µm² die at 40% utilization, fmax of 111.79 MHz, zero setup/hold/DRC violations, and clean routing in three iterations.

NOMA Uplink Access Channel — FPGA Implementation

PAPER SUBMITTED

Non-orthogonal multiple access system implemented on a Terasic DE1-SoC (Cyclone V), verified in ModelSim — BPSK modulation, fixed-point power scaling, superposition coding, and a SIC receiver. Backed by an 11-plot MATLAB simulation and submitted as an IEEE conference paper to NMITCON 2026.
